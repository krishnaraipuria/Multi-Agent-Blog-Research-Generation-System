# BlogForge AI

### Multi-Agent AI Blog Generation System

BlogForge AI is an AI-powered multi-agent system that researches a given topic, creates a structured content plan, generates different blog sections using specialized agents, and combines them into a coherent final blog.

## Workflow

User → Router → Researcher → Orchestrator → Multiple Workers → Reducer → Final Blog

## Tech Stack

- Python
- LangGraph
- LangChain
- LLM
- Web Search
- Streamlit

## Key Features

- Multi-agent architecture
- Automated web research
- AI-based content planning
- Parallel blog section generation
- Final content synthesis
- Structured, research-backed blog output

## Goal

Build an autonomous AI workflow that can go from **topic → research → planning → writing → final blog** with minimal human intervention.
